# Automatic Kitchen Void Slip on Post-Print Cancellation

When a settled order is cancelled after tickets have printed, kitchen cooks may already be assembling the food. We decided that every supervisor-authorized order void must automatically print an ESC/POS Void Slip on the kitchen printer featuring an inverted alert banner, the Token number, and cancellation reason. This eliminates reliance on verbal staff shouts across a noisy kitchen, stops food preparation immediately, and prevents inventory loss on abandoned orders.
