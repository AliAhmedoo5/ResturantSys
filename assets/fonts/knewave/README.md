# Knewave

Knewave is a painted display font by Tyler Finck, distributed under the SIL Open Font License 1.1. The unmodified font and its original copyright/licence are bundled for offline use.

Source: https://github.com/google/fonts/tree/130fcfb0ff422fec96b335616b2ca99f91914792/ofl/knewave

- `Knewave-Regular.ttf`: original regular 400 font, without synthetic bold or italic.
- `OFL.txt`: original licence; also included as a Flutter asset and registered with `LicenseRegistry`.

Use `WarmCounterTypography.brandHeading` for branded screen titles and promotional headings. Keep `pageHeading`, body, PIN keypad, menu labels, prices, table amounts and form controls in the operational font. The generated Crunch Cartel wordmark remains separate artwork.
